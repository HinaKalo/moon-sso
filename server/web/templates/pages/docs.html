2. 协议要点

  • 只支持授权码模式，所有客户端都必须使用 PKCE S256。授权响应带 iss 参数（RFC 9207），请同时校验 state 和 iss。
  • Access Token 是 JWT（ES256，typ: at+jwt），有效期 {{.Site.AccessTokenMinutes}} 分钟，资源服务器可以用 JWKS 在本地校验。ID Token 默认 RS256。
  • Refresh Token 每次使用都会轮换。同一个旧令牌在 60 秒内重复提交时，服务端返回同一个新令牌，所以多标签页、多进程同时刷新和网络重试都是安全的。超过宽限期再次使用会被判定为盗用，这一组令牌全部作废。
  • 浏览器单页应用、桌面和移动应用建议开启 DPoP（RFC 9449）：refresh token 与设备密钥绑定，被窃取后在其他设备上无法使用。
  • 第三方应用拿到的 sub 按应用区分（pairwise），以保护用户隐私。请以 sub 作为用户主键，不要用用户名，因为用户名可以修改。

4. 应用内修改资料并同步

拿到 profile:write 的应用可以调用 PATCH /api/v1/me 修改用户名和昵称，调用 PUT /api/v1/me/avatar 上传头像；拿到 password:write 的应用可以调用 POST /api/v1/me/password 修改密码（需要当前密码）。修改后会通过以下方式同步给其他应用：

  • Webhook：Standard Webhooks 格式签名（webhook-id、webhook-timestamp、webhook-signature），每个应用按顺序投递，失败自动重试，最长重试 24 小时。
  • 实时事件：GET /api/v1/me/events（SSE，使用 Bearer 令牌），适合桌面、移动端和网页，断线后凭 Last-Event-ID 续传。
  • 变更流：GET /api/v1/users/changes?cursor=（client_credentials + users:sync），用于对账和补偿。
  • Back-Channel Logout：用户退出或在 SSO 中移除设备时，通知应用后端立即结束对应会话。

5. 第一方应用的应用内登录

管理员把应用标记为“第一方”并开启“允许应用内登录”后，应用可以用自己的登录界面调用 POST /oauth/authorize-challenge。账号开启了两步验证时，接口会要求再提交一次验证码。注册新用户调用 POST /api/v1/native/register（需要开放自助注册）。各 SDK 都封装了这两个流程。

6. API 令牌与命令行接入

API 令牌是给终端、脚本和 CI 用的长期凭证，直接放在 Authorization: Bearer 里调用，不需要走 OAuth 授权流程。令牌分两类，互不通用：

类型在哪里创建调用地址权限最长有效期
开发者令牌
msso_dev_…		开发者中心 → API 令牌{{.Data.Issuer}}/api/v1/developerapps:read · apps:write365 天
控制台令牌
msso_adm_…		超级管理员控制台 → API 令牌（需验证码）{{.Data.AdminURL}}/api/v1stats:read · users:read/write · clients:read/write · settings:read/write · audit:read90 天
  • 只显示一次：服务器只保存令牌的 HMAC 指纹，丢失后只能轮换或重新创建。
  • 到期与提醒：每个响应都带 Moon-Token-Expires-At（RFC 3339）和 Moon-Token-Expires-Soon（剩余不足 7 天且不足有效期四分之一时为 true），页面和命令行据此提醒轮换。
  • 轮换：POST …/token/rotate，可选 {"grace_seconds": 3600}（0–604800，默认 1 小时）。新令牌继承名称、权限、IP 白名单和原有效期；宽限期内旧令牌仍可用，响应带 Moon-Token-Rotated: true。
  • 吊销：DELETE …/token 吊销当前令牌；也可在页面吊销。管理员重置密码、停用或删除账号时，该账号的令牌立即失效。
  • IP 白名单：可限制为若干 IP 或网段（IPv4/IPv6），其他来源返回 403 ip_not_allowed。
  • 审计：所有操作以令牌所有者的身份记入审计日志，并标注 token:…。
  • 错误：401 invalid_token（无效、过期、吊销或站点不对）、403 insufficient_scope、422 validation_failed（带 field）、429 rate_limited（带 Retry-After）。

命令行工具 moonsso

安装（Go 1.27+）：

go install sso.moonl.cloud/sdk/go/cmd/moonsso@latest

或在 SDK 下载 页面下载 Windows / macOS / Linux 的预编译文件。登录后令牌保存在本机配置目录（权限 0600），开发者令牌和控制台令牌分开保存：

moonsso login                      # 粘贴令牌（不回显），按前缀自动识别类型
moonsso whoami
moonsso apps list
moonsso apps create --name "My App" --type web --redirect-uri https://myapp.example/callback
moonsso apps update ms_xxx --set client_name=新名字 --set require_dpop=true
moonsso apps rotate-secret ms_xxx
moonsso token rotate --grace 1h    # 自动保存新令牌

moonsso admin stats                # 使用控制台令牌
moonsso admin users list --q alice
moonsso admin users disable alice
moonsso admin settings set registration_open=false
moonsso admin audit --actor @admin --limit 20
moonsso api GET apps               # 任意接口的原始调用

CI 中可以直接用环境变量：MOONSSO_TOKEN（开发者令牌）或 MOONSSO_ADMIN_TOKEN（控制台令牌）。加 --json 输出原始 JSON。

直接用 curl

# 开发者：创建应用（RFC 7591 元数据）
curl -X POST {{.Data.Issuer}}/api/v1/developer/apps \
  -H "Authorization: Bearer $MOONSSO_TOKEN" -H "Content-Type: application/json" \
  -d '{"client_name":"My App","redirect_uris":["https://myapp.example/callback"]}'

# 开发者：部分修改（未提供的字段保持不变）
curl -X PATCH {{.Data.Issuer}}/api/v1/developer/apps/ms_xxx \
  -H "Authorization: Bearer $MOONSSO_TOKEN" -H "Content-Type: application/json" \
  -d '{"webhook_url":"https://myapp.example/hooks/sso"}'

# 轮换当前令牌，旧令牌再保留 1 小时
curl -X POST {{.Data.Issuer}}/api/v1/developer/token/rotate \
  -H "Authorization: Bearer $MOONSSO_TOKEN" -d '{"grace_seconds":3600}'

# 超级管理员：停用用户、关闭自助注册
curl -X POST {{.Data.AdminURL}}/api/v1/users/alice/disable -H "Authorization: Bearer $MOONSSO_ADMIN_TOKEN"
curl -X PATCH {{.Data.AdminURL}}/api/v1/settings -H "Authorization: Bearer $MOONSSO_ADMIN_TOKEN" \
  -H "Content-Type: application/json" -d '{"registration_open":false}'

完整接口定义：开发者 API 见 {{.Data.Issuer}}/openapi.yaml（developer 标签）；超级管理员 API 见 {{.Data.AdminURL}}/openapi.yaml。
